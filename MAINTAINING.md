# Maintaining this template

This repository is the template. Work here is template maintenance, not project work: do not run the phase skills, and do not change PHASE or STATUS in `docs/TASKS.md` or the placeholders in `docs/PROJECT.md`; those are the starting point for derived projects.

This is a solo project: commit directly to `main`. Agents do not push.

docs/WORKING-AGREEMENT.md holds the defaults for derived projects; the template's own way of working is in this file.

The template ships ready to use: no history, tombstones, amendment notes or "previously…" wording in shipped files. Template history lives in git.

Everything else follows [`AGENTS.md`](AGENTS.md).
